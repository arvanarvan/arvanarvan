# Arvanarvan Website

Professional responsive fashion website for **Arvanarvan**.

## Files

- `index.html` — main website
- `styles.css` — design and responsive styling
- `script.js` — menu, filters, cart counter, and newsletter interactions

## GitHub Pages

Upload all files to the root of your GitHub repository, then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

The website uses remote fashion photography from Unsplash and Google Fonts, so an internet connection is required for those assets to load.
